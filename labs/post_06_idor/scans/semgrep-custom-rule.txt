    ❯❱ rules.thiagoteixeira.django.security.idor.object-lookup-without-owner-scope
          ❰❰ Blocking ❱❱
          A get_object_or_404 / get_list_or_404 lookup is scoped to the whole table, not to the requesting
          user. Being authenticated is not being authorised: if the primary key comes from the URL, any   
          logged-in user can read another user's object by walking the ids - an Insecure Direct Object    
          Reference (IDOR). Scope the lookup to the owner so a foreign id simply 404s:                    
          get_object_or_404(Model, pk=pk, owner=request.user).
