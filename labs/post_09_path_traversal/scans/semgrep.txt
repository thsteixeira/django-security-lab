    ❯❱ rules.thiagoteixeira.django.security.path-traversal.request-data-reaches-open
          ❰❰ Blocking ❱❱
          Data from the request reaches a file read - open(), or a path's .open(), .read_bytes() or         
          .read_text() - without passing through safe_join(). os.path.join and pathlib's / operator do not  
          contain their result: a '../' segment climbs out of the base directory, and an absolute component 
          (e.g. '/etc/passwd') discards the base entirely - so the caller can read any file the process can.
          This is path traversal (CWE-22). Build the path with django.utils._os.safe_join(), which raises   
          SuspiciousFileOperation when the resolved path escapes the base, or resolve the file through a    
          FileField / Storage instance instead of a raw path.
