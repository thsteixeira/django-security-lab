    ❯❱ rules.thiagoteixeira.django.security.mass-assignment.model-fields-all
          ❰❰ Blocking ❱❱
          A ModelForm/ModelSerializer Meta uses fields = "__all__", so every editable field on the model is 
          bindable from the request — including any permission field (is_staff, is_superuser, role) or      
          otherwise sensitive column. This is a mass-assignment (over-posting) sink: a client can set fields
          the feature never meant to expose, e.g. POST role=staff to self-promote. Enumerate an explicit    
          allowlist instead: fields = ["display_name", "bio"].                                              
                                                                                                            
           25┆ fields = "__all__"  # DANGER: price, paid, status, owner are all writable
